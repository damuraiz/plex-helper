# Проверка первой версии

Дата: 14 октября 2026. Целевая система — Synology DS920+ с DSM
7.3.2-86009 Update 4. Локальная машина разработки — macOS arm64, Go1.25.14.
Дополнительно [успешный GitHub CI](https://github.com/damuraiz/plex-helper/actions/runs/38596356709)
проверил те же исходники на Ubuntu24.04 x86-64 с Go1.25.14/Python3.12.

## Требует проверки на самом NAS

Локальные service hooks и static ELF не являются эмуляцией Package Center
или подтверждением совместимости с конкретным ядром/ACL DSM. На NAS нужно:

1. Установить SPK в Package Center → Manual Install и проверить мастер пароля;
   предусмотрен setup-token fallback, но Vue wizard ещё не проверен на DSM.
2. Проверить создание system internal user `plex-helper`, выделить ему
   Read/Write только для тестовой общей папки и проверить отказ без прав.
3. Открыть приложение из меню DSM и Package Center, проверить firewall port,
   HTTPS reverse proxy/собственный TLS при выбранной конфигурации.
4. Проверить Run/Stop и автозапуск после reboot; долгую операцию закончить
   до остановки, проверить видимый журнал после прерывания.
5. Повторить scan → выбор метаданных → preview → apply → undo на маленьких
   тестовых видео, с симлинком, конфликтом и изменённым после Apply файлом.
6. Проверить разные тома, права новых файлов для Plex и фактический fsync на
   выбранных файловых системах. Не копируются ACL/xattr/sparse-layout.
7. Установить обновлённый SPK с большим build number, убедиться в сохранении
   настроек и журналов; заранее сделать копию pkgvar.
8. Измерить RAM/CPU на J4125/4GB. GOMEMLIMIT256MiB — мягкая цель Go, а не
   измеренное потребление памяти или гарантия максимального RSS.

Установки/входа на пользовательский NAS в этом процессе не было. Проверка
DSM install/update/reboot остаётся отдельным этапом, а не заявляется завершённой.
