# Plex Helper

Самостоятельное открытое приложение для организации фильмов и сериалов в Plex.
Цель первой версии: **Synology DS920+ / DSM 7.3.2**, нативная установка `.spk`,
веб-интерфейс из меню DSM, вход через текущую сессию администратора DSM. Приложение и файловые операции выполняются на NAS.

Go-сервер и интерфейс упакованы в один статический бинарник Linux x86-64.
На NAS не нужны Docker, Container Manager, Java, Python, Node.js или Go.
Код использует стандартную библиотеку Go, без сторонних модулей и CDN.

## Возможности

- Выбор доступных папок NAS и сканирование видеофайлов.
- Разбор названий, годов, `S01E02`, `1x02`, диапазонов эпизодов, дат,
  специальных выпусков, ID, частей и версий файлов.
- «Подготовить»: сканирование, автоматический выбор однозначных совпадений TMDB
  и общий предпросмотр. Серии одного сериала ищутся одной группой.
- Ручной выбор названия сразу для всех серий; сезоны и номера эпизодов сохраняются.
  Отдельный файл можно исправить независимо. Ручная карточка работает без API.
- Имена и структура Plex: Movies, TV Shows, Season NN, provider IDs;
  сохранение качества/версий и существующих edition/part пометок.
- Предпросмотр «было → станет», исключение ненужных файлов и одна кнопка
  «Переименовать» для всей подготовленной партии.
- Перенос однозначно связанных субтитров вместе с выбранным видео.
- Защита от перезаписи, конфликтов путей, симлинков и изменённого источника.
- Быстрый атомарный перенос внутри тома без чтения видеоданных. Отмена
  проверяет device/inode/размер/mtime/ctime; изменение атрибутов тоже запрещает её.
- Потоковый SHA256 для копирования между томами и восстановления старых журналов.
  Постоянный журнал, прогресс с текущим файлом и остановка обработки из браузера.

**Это первая версия для проверки медиатеки на NAS.** На DS920+ проверены
установка/обновление и открытие через текущую сессию DSM без второго пароля.
DSM ACL /volume1/video и чтение подпапок проверены. Автозапуск после reboot
ещё требует проверки. Быстрый Apply/Undo на NAS проверен на отдельном искусственном файле. Разработка и локальные проверки не затрагивают
настоящую медиатеку. Начните с отдельной тестовой общей папки.

## Установка и сборка SPK

Подробная инструкция: [docs/SYNOLOGY.md](docs/SYNOLOGY.md).

```sh
make test
make package-test
make spk
```

Машина сборки: Go **1.25.14**, Python **3.12**, make. На macOS можно передать
`GO=/opt/homebrew/bin/go`; Python используется только упаковщиком, а не на NAS.
Builder не скачивает toolchain или зависимости. Для побайтовой сверки между
машинами нужны одинаковые исходники, Go и Python/zlib.

Результат: `dist/plex-helper-x86_64-0.3.0-1.spk` и `.spk.sha256`.
В DSM: **Package Center → Manual Install**. Доступ к тестовым папкам выдается
внутреннему пользователю системы **plex-helper** средствами DSM.

## Первый рабочий сценарий

1. Создайте отдельную тестовую общую папку на NAS и две подпапки: `incoming`
   и `library`. Поместите небольшие тестовые видео/субтитры в `incoming`.
2. Установите и запустите пакет, откройте Plex Helper из меню DSM и войдите
   с уже выполненным входом администратора DSM. Отдельного пароля приложения нет.
3. В настройках выберите обе папки и язык. Для поиска добавьте **собственный
   TMDB API Read Access Token или API key**; он хранится в файле настроек с правами `0600`
   и не возвращается браузеру после сохранения. API TMDB использует интернет.
4. Выберите папку и нажмите **«Подготовить»**. TMDB ищет каждый сериал один раз;
   однозначные совпадения получают названия и номера серий и сразу попадают
   в предпросмотр. Пока ничего не изменено.
5. Если сериал выбран неверно, нажмите его название над списком серий,
   найдите нужный вариант и выберите результат: он применится ко всей группе.
   В режиме «Только к этому файлу» можно исправить отдельную серию.
6. Проверьте **«было → станет»**, снимите отметки с ненужных файлов и нажмите
   **«Переименовать»** один раз. Неразрешённые строки не входят в план.
7. В журнале нажмите отмену. Если содержимое файла изменилось или исходный
   путь занят, приложение откажется менять этот файл и сохранит журнал.

Папка библиотеки должна существовать. Она не может находиться внутри папки
сканирования; исходники могут быть подпапкой общей медиапапки. Перед
применением дождитесь окончания загрузок: приложение не блокирует чужие
процессы, которые продолжают писать в файл. Подключённые сетевые файловые
системы должны поддерживать эксклюзивное переименование и fsync. Проверяйте
ACL для Plex отдельно: перенос между томами создаёт новый файл с правами
назначения. ACL, расширенные атрибуты и sparse-layout между томами не копируются.

## Локальный запуск для разработки

```sh
go build -o plex-helper ./cmd/plex-helper
./plex-helper --data ./local-data
```

Откройте `http://127.0.0.1:8650`. Для первой настройки используйте код из
`local-data/setup-token` и задайте отдельный пароль. Это режим разработки
`--auth local`. NAS-пакет всегда использует `--auth dsm`, слушает только
127.0.0.1:8650 за прокси DSM и не запрашивает пароль приложения.

Для инициализации без интерфейса используйте `--init-password`, передавая
пароль только через stdin. Повторная инициализация существующего пароля
запрещена. `--tls-cert` и `--tls-key` включают собственный HTTPS в локальном
режиме. Для NAS-пакета HTTPS и авторизацию предоставляет DSM.

## Границы первой версии

- Онлайн-провайдер — TMDB; TVDB/IMDb ID можно указать вручную, поиска через
  их API пока нет. Токен TMDB не поставляется с приложением.
- Нумерация TMDB aired; absolute/DVD/anime порядки не угадываются. Для
  неоднозначного имени нужны ручные сезон и эпизоды.
- Дата эфира поддерживается в имени при явно выбранном сезоне; онлайн
  сопоставление по дате пока не выполняется.
- 10 000 видео на один скан. Черновики сканов/планов живут в памяти; после
  перезапуска нужен новый скан. Настройки и выполненные журналы сохраняются.
- Операции выполняются последовательно; для больших файлов проверка хэша
  занимает время. Пока нет фоновой очереди или автоматического наблюдения.
- Симлинки, неоднозначные субтитры и декомпозированные Unicode-компоненты
  нового имени требуют отдельного решения; защищённый путь не обходится.
- Выполненные перенесённые строки можно отменить после перерыва по журналу.
  Изменённые файлы и конфликты исходного пути требуют ручного рассмотрения.

## Автоматический выбор и группы

Группа сериала определяется по названию из исходных имён, году и явному
provider ID; сезоны не разделяют один сериал. Разные годы/ID не объединяются,
фильмы рассматриваются отдельно. Неизвестные номера эпизодов не копируются
с первой серии. TMDB запрашивается отдельно для всех нужных сезонов.

Автоматически выбирается единственный результат с совпадающим оригинальным
или локализованным названием и совместимым годом (либо явный TMDB ID файла).
Похожие названия и несколько одноимённых сериалов требуют выбора пользователем.
Порядок результатов TMDB сам по себе не служит основанием для выбора.
Ошибки API и неизвестные номера серий не меняют файлы.

## Переименование и остановка (0.2.1)

При выборе `/volume1/video/TV Shows` сериал размещается непосредственно в
`The Idol (2023) {tmdb-135251}/Season 01/`, без повторного `TV Shows`.
Общая папка `/volume1/video` по-прежнему создаёт Movies/TV Shows.
Язык поиска и карточек независим от языка имён папок/файлов (по умолчанию English).
Ручная карточка позволяет явно задать название для файлов.

Обычный перенос внутри тома не читает видео: проверяет атрибуты и выполняет
эксклюзивное атомарное переименование. Отмена проверяет сохранённый fingerprint
после переноса, включая ctime, и отказывается от замены/изменённого файла.
Если сбой произошёл между rename и записью нового fingerprint, программа
не угадывает содержимое и требует ручной проверки; сам файл сохраняется.
Строгое сравнение ctime может отказать в отмене после chmod или изменения ACL.

Старые журналы 0.2.0 требуют SHA256: обычный возврат единственной копии внутри
тома проверяет содержимое один раз, затем использует ctime/inode/size/mtime для
защиты до атомарного возврата. Уже возвращённая единственная копия также проверяется
один раз и отмечается в журнале без повторного переноса. Сложное восстановление
из staging/дубликатов и копирование между томами сохраняют дополнительные проверки.
Счётчик отмены включает только файлы, которые действительно требуют восстановления.
Прогресс показывает текущую проверку/копирование.
Журнал читается независимо от выполняющейся файловой операции. Обновление
страницы сохраняет отображение прогресса. «Остановить обработку» останавливает
проверку/копирование на контрольной точке; атомарный rename завершается до
остановки. Выполненные операции остаются в журнале, отмена запускается отдельно.
Штатная остановка пакета DSM также запрашивает остановку обработки.


## Выбор отдельных файлов (0.3.0)

В шаге 1 выберите «Отдельные файлы» → «Выбрать файлы». Откроется список
видеофайлов на NAS: можно перейти в нужную папку, отфильтровать имена и отметить
один или несколько файлов. Галочки сохраняются при переходах между папками.
«Выбрать все показанные файлы» действует только на результаты текущего фильтра.
Закрытие окна не меняет уже подтверждённый выбор. Выбранные пути видны в шаге 1,
каждый можно убрать отдельно или очистить список. «Подготовить» распознаёт
только эти файлы; соседние фильмы в общей папке не попадают в скан/поиск/план.

Файлы остаются на NAS, загрузки через компьютер нет. Подтверждение выбора
не переименовывает файлы: операции применяются только после предпросмотра и
нажатия «Переименовать». Связанные субтитры добавляются в предпросмотр автоматически;
если рядом есть второй видеоконтейнер с тем же именем, общий субтитр оставляется
на месте. После применения выполните новый выбор или сканирование.
Режим «Целая папка» сохраняет прежнее рекурсивное сканирование.
