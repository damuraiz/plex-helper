Настройки папок и метаданных

Получите собственный токен в настройках API аккаунта TMDB. Пакету нужен доступ на чтение и запись к выбранным папкам: DSM → Панель управления → Общая папка → Разрешения → Внутренний пользователь системы → plex-helper.

Выполняется операция

Обновление страницы не прерывает обработку. «Остановить обработку» сохранит выполненные операции в журнале; отмена выполняется отдельно.
